# 陪伴功能更新公告

更新时间：2026-09-01 08:45 +08:00

以下文案面向已经启用对应功能的机器人实例，可直接用于 QQ 私聊说明、群公告或版本更新日志。

## 群公告短版

```text
【陪伴功能更新】

这次更新把陪伴功能补得更完整了：现在可以记下想跟进的事情、按需回顾最近的相处记录、控制机器人记忆什么，还可以在明确要求时收到语音回复；原有的限时陪伴房间也支持共读、共看、共听，并新增了手机可用的陪伴房间页面。

可以这样说：
1. “记一下：我周五要交报告。”
2. “我还有哪些没做完的事？”
3. “回顾一下今天我们聊了什么。”
4. “请记住我喜欢晚上听音乐。”
5. “你现在记得我什么？”或“忘掉关于这件事的记忆。”
6. “陪我共读《三体》30 分钟，看到第三章告诉你。”
7. “把这段用语音说给我听。”

共处房间还支持：
• 专注、放松，以及共读、共看、共听
• 15、30、45、60、120 分钟计时
• 暂停、继续、结束、记录进度
• 安静、偶尔聊聊、多聊三种陪伴密度
• 查看最近共同回忆

说明：陪伴回顾与 QQ 内的共处房间只支持私聊；语音回复需要管理员先启用，且只有你明确要求时才会发送，不会自动把普通文字变成语音。共读、共看、共听不会下载或同步播放媒体，机器人只根据你提供的标题和进度陪你进行。

如果实例已经完成配置并开放 Web 陪伴房间，登录 Web 管理会话后可以访问 /companion-room/；页面与 QQ 共用同一个房间状态，手机上也可以安装使用。离线时只能查看最近状态，不能把未成功的操作显示成成功。
```

## 更新日志长版

```text
【更新公告｜让陪伴更有连续性，也更听你的安排】

本次更新集中完善了 QQ 私聊陪伴体验，新增和扩展了以下能力。

一、待跟进事项

你可以把明确的承诺、计划或关心事项交给机器人记下，例如：

“记一下：我周五要交报告，先整理错题本。”
“我还有哪些没完成的事情？”
“把准备考试材料标记为已完成。”
“把提交作业延期到明天。”

事项按用户分别保存。后续主动私聊陪伴可以参考未完成事项，但机器人不会擅自把事项标记完成、延期或删除；这些变化需要你明确提出。

二、按需陪伴回顾

直接说：

“回顾一下今天。”
“看看我们昨天聊了什么。”
“总结最近七天的相处记录。”

机器人会按你选择的时间范围整理可用的相处记录，并附上当前未完成的待跟进事项。回顾是按需查询，不会因为这项功能自动定时推送，也不开放群聊查看。

三、用户可控记忆

你可以直接询问或管理自己的长期记忆：

“你现在记得我什么？”
“请记住我喜欢晚上听音乐。”
“把我喜欢这个作家的记忆改成我最近更喜欢另一位作家。”
“忘掉关于这件事的记忆。”
“关闭自动记忆。”

查看、明确保存、更正和遗忘都只作用于当前私聊用户。关闭自动记忆后，机器人不再隐式提取用户画像、生成每轮长期摘要或执行后台长期学习；你明确要求记住的内容、短期对话上下文和日常记录仍按原有规则工作。涉及保存、更正、开关和遗忘的操作会先向你确认。

四、共读、共看、共听

原有 `/陪伴` 共处房间现在可以围绕具体内容开始：

/陪伴 开始 共读 三体 30分钟
/陪伴 开始 共看 葬送的芙莉莲 45分钟
/陪伴 开始 共听 世界计划音乐 30分钟
/陪伴 进度 看到第 3 章

也可以继续使用自然语言：

“陪我学习半小时。”
“陪我放松一下。”
“陪我共读《三体》30 分钟。”
“安静一点。”
“多陪我聊聊。”

房间支持 15、30、45、60、120 分钟，以及开始、暂停、继续、结束、切换活动、查看状态、记录进度和查看共同回忆。内容标题和最后进度会进入房间状态与结束回忆，方便下一次接着聊。

功能边界：机器人不会下载、播放或同步你正在看的书、视频或音乐，也不会假装自己实际读过、看过或听过；它只依据你提供的标题、进度和对话内容陪伴你。

五、QQ 私聊按需语音

启用语音能力后，你可以明确说：

“把上一段用语音说给我听。”
“朗读这段。”
“用语音回复我。”

只有在 QQ 私聊中明确提出语音要求时才会调用语音回复；普通聊天、群聊和主动私聊仍然发送文字，不会自动转语音。单条语音最多 300 字；语音生成或发送失败时，会保留原文字回复，不会重复发送语音。

语音能力默认关闭，需要管理员配置独立的语音服务后才能使用。

六、手机陪伴房间 PWA

已完成配置的实例提供独立的 `/companion-room/` 页面。登录 Web 管理会话后，可以在手机或桌面浏览器中操作当前绑定用户的陪伴房间：

• 开始专注、放松、共读、共看或共听
• 查看剩余时间，暂停、继续或结束房间
• 记录内容进度，切换安静、偶尔、多聊的陪伴密度
• 查看最近共同回忆
• 安装为 PWA，在手机主屏幕直接打开

Web 页面和 QQ 命令使用同一个房间状态，不会产生两套计时或回忆。页面固定绑定一个 QQ 用户，不能通过请求参数切换到其他用户；离线时保留最近一次成功读取的状态，但离线写操作不会伪装成功。

使用提醒：共处房间默认关闭，需要管理员先执行 `/陪伴插件 开启` 或完成配置。PWA 还需要绑定 `COMPANION_ROOM_WEB_USER_ID`，并使用已登录的 Web 管理会话访问；语音回复也需要单独启用。不同实例的启用情况可能不同，请以当前机器人实际回复为准。
```

## 功能边界

- 陪伴事项、陪伴回顾、用户可控记忆和按需语音均面向 QQ 私聊，不开放群聊中的个人陪伴数据管理。
- 陪伴回顾不会自动定时推送；待跟进事项不会被机器人自行完成、延期或删除。
- 共读、共看、共听只保存用户提供的标题和进度，不下载、播放或同步媒体。
- 语音回复默认关闭，只响应用户明确提出的语音要求，单条最多 300 字。
- PWA 需要已登录的 Web 管理会话和固定的 QQ 用户绑定；离线只读展示最近状态。
