# 舞萌谱面查询与成绩分析使用说明

更新时间：2026-08-04 13:05 +08:00

这项功能可以查询舞萌曲目和谱面、分析单张谱面的结构与手法，并在你主动绑定成绩后，根据当前成绩推断可能的手法弱项。普通谱面查询不需要绑定账号，群聊和私聊都能使用。

## 快速开始

私聊时直接提问即可。群聊中建议先 `@机器人`，并在问题里写明“舞萌”或“maimai”，避免消息被当作普通聊天忽略。

例如：

```text
@机器人 舞萌找 5 张定数 13.7 到 14.0 的 DX 紫谱，偏滑键。
```

```text
@机器人 比较舞萌 PANDORA PARADOXXX 紫谱和白谱的定数、物量。
```

```text
@机器人 分析舞萌 PANDORA PARADOXXX 白谱，告诉我主要手法和代表高强度段。
```

如果机器人回复“舞萌功能当前未启用”，说明当前实例尚未开放该功能，请联系管理员。

为了避免普通聊天被误认为谱面查询，建议每次都在当前问题里写明“舞萌”或“maimai”，再说明要查的谱面数据。机器人不会从上一轮继承舞萌语境，所以不要只发“这张呢”；请重新写出曲名、标准/DX 和难度。单独讨论写作手法、UI 交互、键盘滑键、蓝牙掉音或数学定数不会触发舞萌查询，“舞萌好玩吗”之类闲聊也会正常聊天。

## 找歌和筛谱

可以在一句话中组合这些条件：

- 曲名或曲名的一部分。
- 定数范围，例如“13.7 到 14.0”。
- 谱面类型：标准谱（SD）或 DX 谱。
- 难度：绿谱、黄谱、红谱、紫谱、白谱。
- 手法倾向，例如纵连、交互、滑键或双押。
- 返回数量，最多 10 张。

常用问法：

```text
舞萌找 5 张定数 12.5 到 13.0 的标准红谱。
```

```text
舞萌有哪些 14 级 DX 紫谱？
```

```text
舞萌找 5 张定数 13.7 到 14.0 的 DX 紫谱，偏滑键。
```

```text
舞萌搜索“月に叢雲華に風”，列出标准谱和 DX 谱。
```

```text
比较舞萌 PANDORA PARADOXXX 紫谱和白谱，哪个定数更高，物量差多少？
```

等级和定数不是同一个概念。如果你希望筛选更精确，请明确说“定数”；只说“13+”时，机器人会按谱面等级理解。

多谱筛选、推荐和比较会优先走搜索，因此可以把定数、谱面类型、难度和手法倾向写在同一句里。搜索结果仍是候选列表；想看完整结构和代表段时，再指定其中一张谱面做单谱分析。

## 分析一张谱面

单谱分析适合回答“这张谱难在哪里”“主要练什么手法”“代表高强度段是什么”这类问题。最好同时提供完整曲名、标准/DX 和难度。

```text
分析舞萌 PANDORA PARADOXXX 标准白谱，重点看纵连、交互和变速。
```

```text
舞萌 PANDORA PARADOXXX 标准白谱有什么手法，物量和峰值密度怎么样？
```

分析结果可能包含：

- 等级、定数、总物量和各类 note 数量。
- 密度、峰值密度、双押、交互、纵连、滑键组合和 BPM 变化。
- 最多 3 个代表性高强度时间段及其谱面片段。
- 当前数据版本、同步时间、映射置信度和检索是否降级。

代表段是根据谱面结构离线计算出来的高强度片段，不代表你本人一定会在这里失误。机器人不能知道你实际游玩时的掉音位置。

如果同名曲目、标准/DX 或难度不明确，机器人最多列出 5 个候选，不会自动选择第一项。按候选中的完整曲名、谱面类型和难度重新发送完整问题即可。

## 绑定个人成绩

只有个人成绩分析需要绑定。为了避免 Import-Token 出现在群聊中，绑定必须在机器人私聊完成。

1. 从你使用的兼容成绩服务获取 Import-Token。服务页面可能调整入口，请以该服务当前说明为准。
2. 打开机器人私聊，发送：

```text
/mai bind <Import-Token>
```

3. 机器人会先验证 Token，再保存成绩。成功时会回复已验证的成绩数量；验证失败时不会保存 Token。
4. 发送 `/mai status` 确认绑定状态和谱面数据版本。

不要在群聊、截图或转发消息中公开 Import-Token。绑定命令不会进入机器人的主模型、聊天记忆、被动感知和诊断正文，但 QQ 客户端或平台本身仍可能保留你的私聊消息记录。

## 使用个人成绩分析

绑定成功后，可以直接用自然语言提问：

```text
根据我的成绩分析舞萌手法弱项。
```

```text
根据我的成绩分析舞萌弱项，重点看纵连。
```

```text
根据我的成绩分析舞萌弱项，看看交互和滑键。
```

弱项结论是“基于成绩相关性的推断”，不是对单次游玩的复盘。系统至少需要 20 张有效成绩，单项手法至少需要 8 张非零样本；没有达到条件或相关性不明显时，机器人会明确说样本不足或没有显著弱项。

如果想根据弱项找练习谱，建议分两次问：

```text
根据我的成绩分析舞萌手法弱项。
```

得到结论后再发送：

```text
舞萌找 5 张定数 13.0 到 13.6 的 DX 紫谱，偏纵连。
```

多谱搜索可以直接附加手法倾向。需要进一步分析时，请从候选中指定完整曲名、标准/DX 和难度，例如“分析舞萌 PANDORA PARADOXXX 标准白谱的纵连和代表高强度段”。

个人分析也能在群聊使用，但回复会被群成员看到。涉及成绩、弱项或个人表现时，建议在私聊中提问。

## 成绩相关命令

| 命令 | 作用 | 使用位置 |
| --- | --- | --- |
| `/mai` | 等同于查看状态 | 群聊或私聊 |
| `/mai status` | 查看是否绑定及当前谱面数据版本 | 群聊或私聊 |
| `/mai bind <Import-Token>` | 验证并绑定成绩 | 仅私聊 |
| `/mai refresh` | 立即刷新成绩 | 群聊或私聊，建议私聊 |
| `/mai unbind` | 删除本地 Token、成绩快照和弱项推断 | 群聊或私聊，建议私聊 |

成绩快照在 15 分钟内会直接复用，不需要频繁执行 `/mai refresh`。刷新失败但存在旧快照时，机器人会继续使用旧快照并标注抓取时间；没有可用快照时会提示重新绑定。

`/mai unbind` 只清理机器人本地保存的数据，不会替你撤销外部成绩服务签发的 Token。如需让 Token 在外部服务失效，请到对应服务操作。

## 数据和回答边界

- 谱面数据默认每天同步一次，刚更新或刚追加的谱面可能暂时查不到。
- 低置信映射会被隔离，因此部分曲目只能看到基础信息，不能获得完整谱面分析。
- 语义检索不可用时会自动退回 SQL 查询，并在结果中标记降级状态。
- 查询结果只反映当前数据版本，不代替游戏内官方信息。
- 机器人不能读取你的游玩录像、判定明细或真实掉音点，也不会修改游戏数据。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 群聊中没有响应 | `@机器人` 后重新发送完整问题，并明确写“舞萌”或“maimai”。 |
| 只发“这张呢”没有继续分析 | 当前版本不继承上一轮舞萌语境，请重新写出曲名、标准/DX 和难度。 |
| 找到了同名曲目 | 补充完整曲名、标准/DX 和绿黄红紫白难度。 |
| 定数筛选不准确 | 明确使用“定数 13.7 到 14.0”，不要只写“13+”。 |
| 提示没有完整谱面数据 | 该谱面可能尚未同步或映射置信度不足，可以稍后再查。 |
| `/mai bind` 提示失败 | 检查 Token 是否完整、有效且没有空格；仍失败时联系管理员。 |
| `/mai refresh` 使用旧快照 | 外部成绩服务暂时不可用，回复中的时间就是旧快照抓取时间。 |
| 绑定后没有弱项结论 | 有效成绩或某项手法样本不足，或没有达到显著相关阈值。 |
| 想知道具体哪里掉音 | 当前功能无法读取单局判定，代表段只能说明谱面结构强度。 |
