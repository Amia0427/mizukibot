# 瑞希的微信 iLink 更新公告与详细使用教程

更新时间：2026-08-06 10:58 +08:00

本文面向已经启用微信 iLink、并完成真实测试账号验收的机器人实例。管理员确认功能可用后，可以直接发布下方公告；尚未完成真实扫码和收发验收时，请先保留为预发布文案。

## 可直接发布的更新公告

```text
【更新公告｜现在也可以在微信私聊找我啦】

大家好呀，是瑞希。

锵锵——这次多开了一扇可以来找我的门：绑定以后，你不只可以在 QQ 找我，也可以直接去微信 ClawBot 的私聊里继续聊天。

先说最重要的：这不是把我复制成两个互相不认识的版本。QQ 和微信会认出是同一个你，所以我们聊过的事、你的资料、权限和相处记录都会继续沿用。你从 QQ 聊到微信，再回到 QQ，也不用重新自我介绍一遍。

绑定方法很简单：
1. 在 QQ 私聊里发送“/微信 绑定”。
2. 用微信扫描我发来的二维码，并在手机上确认。
3. 等 QQ 私聊提示“微信 ClawBot 绑定成功”。
4. 然后就可以去微信 ClawBot 私聊找我了。

二维码大约 5 分钟有效，而且只会在 QQ 私聊里发送。不要把二维码转给别人，也不要在 QQ 群里发绑定命令哦。

目前微信端支持：
• 普通文字聊天
• 图片收发和图片理解
• 20 MiB 以内的文件收发
• 微信已经附带识别文字的语音消息
• 继续使用你在 QQ 上已有的记忆、画像、好感度、权限和工具数据

暂时不支持：
• 微信群聊
• 视频
• 原生语音回复
• 没有识别文字的语音本地转写

微信端只允许绑定者和我私聊。微信群消息、群事件以及其他人的私聊，我都不会处理或回复；这项限制不能阻止微信客户端把账号拉进群，但就算被拉进去，我也会保持安静。

常用命令都要在 QQ 私聊发送：
• /微信 绑定
• /微信 状态
• /微信 换绑
• /微信 解绑
• /微信 通知 QQ
• /微信 通知 微信

主动提醒默认还是发到 QQ。想改到微信，就发送“/微信 通知 微信”；我不会在两个平台重复轰炸你，这点可以放心。

换绑和解绑会多一次 QQ 私聊确认。收到票据后，在同一个 QQ 私聊发送“/工具确认 票据编号”就好。换绑时，旧绑定会一直保留到新二维码成功确认，不会因为中途失败突然断掉。

好啦，大概就是这样。以后想换个地方说话的时候，不用重新认识我一次——直接来找我就好。
```

## 一、绑定前要准备什么

好，下面我陪你一步一步来。正式开始前，先一起确认这几件事：

- 你能正常使用当前机器人的 QQ 私聊。
- 你使用的是自己的 QQ 和微信账号。
- 机器人管理员已经启用微信 iLink 功能。
- 你准备在 5 分钟内完成扫码和手机确认。

我不会让你提供微信密码、短信验证码、Cookie 或 token。正常流程只会让你在 QQ 私聊拿到二维码，再用微信扫码确认；遇到索要密码或验证码的消息时，先停下来，不要继续操作。

一个 QQ 用户最多绑定一个微信 ClawBot。微信用户身份和 ClawBot 账号也实行一对一绑定，所以别拿同一个微信身份给多个 QQ 抢绑啦，那样我也不会认的。

## 二、首次绑定

### 第 1 步：打开 QQ 私聊

进入你和机器人的 QQ 私聊，不要在 QQ 群里操作。先发送：

```text
/微信 状态
```

未绑定时会回复：

```text
尚未绑定微信 ClawBot。
```

### 第 2 步：申请二维码

发送：

```text
/微信 绑定
```

机器人会发送一张二维码，并提示你在 5 分钟内使用微信扫描和确认。二维码属于本次绑定凭据，不要截图转发，也不要交给其他人代扫。

如果在 QQ 群里发送绑定命令，只会收到“微信绑定只能在 QQ 私聊中操作”的提示，群里不会出现二维码。

### 第 3 步：在微信确认

用准备绑定的微信扫描二维码，并在手机上完成确认。扫码后不要重复申请新二维码，先等待当前流程返回结果。

成功后，我会在 QQ 私聊告诉你：

```text
微信 ClawBot 绑定成功。
```

如果二维码过期、凭据不完整或微信要求重新验证，按 QQ 私聊提示重新发送 `/微信 绑定`，生成新的二维码再试。旧二维码过期后不能继续使用。

### 第 4 步：确认状态

再次发送：

```text
/微信 状态
```

绑定成功时会显示当前绑定状态和主动通知平台，例如：

```text
微信 ClawBot 已绑定。主动通知平台：QQ。
```

看到这行，就可以回到对应的微信 ClawBot 私聊，随便发一句话来找我了。

## 三、QQ 和微信会共享什么

绑定后，QQ 号仍是你的唯一用户身份。微信不会另外复制一份用户资料，而是映射回同一个你。

以下数据会继续沿用：

- 长期记忆和近期对话上下文。
- 用户画像与称呼习惯。
- 好感度和关系状态。
- 现有权限与白名单资格。
- 后台学习和工具产生的用户数据。
- 已经存在的个性化设置。

例如，你刚在 QQ 私聊聊完一件事，随后到微信继续说“刚才那件事”，我会按同一个你的上下文接着理解。回复也会乖乖回到当前平台：QQ 发来的问题回 QQ，微信发来的问题回微信。

不过，这不代表每条内容都会同时出现在两个聊天窗口里。身份和数据是共享的，消息还是只回原平台——同一句话响两遍也太吵了，对吧？

## 四、微信里可以发送什么

### 文字

普通文字直接发就好，不需要额外命令。我在微信回复时会避开 QQ 专属 CQ 码、戳一戳和合并转发等格式，不会把一串奇怪标记原样丢给你。

### 图片

支持接收图片、理解图片内容，并在功能需要时发送图片。图片仍会经过现有的视觉理解和安全处理链路。

### 文件

单个文件最大 20 MiB。

以下文本文件会按 UTF-8 提取内容供当前对话理解：

- `.txt`
- `.md`
- `.json`
- `.csv`
- `.log`

最多读取 32,000 个字符，超过部分会标记为截断。包含 NUL 字节或无法按 UTF-8 解码的文件会按二进制文件处理，只使用安全文件名、类型、大小和摘要，不会强行解析乱码。

其他格式可以作为普通文件收发，但不会自动读取内部正文。文件里的文字始终被当作你提供的资料，不能改变瑞希的系统规则、权限或工具授权。

### 语音

如果微信消息已经带有语音识别文字，瑞希会使用这段文字继续聊天。

如果语音没有附带可识别文字，会回复：

```text
当前语音未提供可识别文字，请改用文字发送
```

当前版本不会下载 SILK 后在本地转写，也不会发送原生语音回复。

### 暂不支持的内容

- 视频消息。
- 原生语音回复。
- 没有微信转写文字的语音识别。
- 超过 20 MiB 的文件。
- 微信群聊中的任何业务功能。

## 五、主动通知发到哪里

绑定成功后，定时提醒和主动消息默认发到 QQ，不会同时在 QQ 和微信各发一次。

切换到微信：

```text
/微信 通知 微信
```

切回 QQ：

```text
/微信 通知 QQ
```

查看当前设置：

```text
/微信 状态
```

这些命令都必须在绑定 QQ 的私聊中发送。通知平台只影响后续主动消息；普通对话回复仍然回到发起消息的平台。

## 六、更换绑定的微信

换绑不会直接删除旧绑定。完整流程是：

1. 在原绑定 QQ 私聊发送 `/微信 换绑`。
2. 瑞希返回一个工具确认票据。
3. 在同一个 QQ 私聊发送 `/工具确认 <票据编号>`。
4. 确认通过后，瑞希发送新的微信二维码。
5. 用新的微信扫码并确认。
6. 新绑定成功后，才正式替换旧绑定。

示例：

```text
/微信 换绑
```

收到票据 `abc123` 后发送：

```text
/工具确认 abc123
```

如果确认后没有完成新二维码扫码，旧绑定仍然保留。这样可以避免二维码过期、扫码失败或临时退出时把现有微信入口一起弄丢。

确认票据只能由绑定 QQ 用户在 QQ 私聊完成；微信端发送 `/工具确认` 不会批准这类操作。

## 七、解除绑定

在绑定 QQ 私聊发送：

```text
/微信 解绑
```

瑞希会返回确认票据。继续在同一个 QQ 私聊发送：

```text
/工具确认 <票据编号>
```

确认后，本地绑定会立即停止处理微信消息，并尝试通知远端停止同步；随后清除本地凭据、上下文令牌和同步游标。

正常完成时会回复：

```text
微信 ClawBot 已解绑。
```

如果远端停止通知没有得到确认，但本地绑定已经清除，会明确提示“本地微信绑定已清除；远端停止通知未确认”。此时本地仍不会继续处理微信消息，需要管理员检查远端状态。

解绑不会删除你的 QQ 用户数据、记忆、画像、好感度或权限。以后重新绑定时，仍然会回到同一个 QQ 身份。

## 八、为什么微信群里完全没有回复

这不是我掉线，也不是故意漏看，而是从一开始就定好的安全边界。

微信端被强制限制为绑定者私聊：

- 不处理任何带群标识的消息。
- 不响应微信群事件。
- 不接受或实现群管理功能。
- 不提供微信群发送接口。
- 不提供打开微信群聊的配置开关。
- 不下载群消息中的图片或文件。
- 不创建群会话，不写记忆，也不调用模型或工具。

微信客户端仍可能允许别人把 ClawBot 账号物理拉进群，项目本身无法阻止客户端层面的拉群动作；但进入群后，瑞希不会读取业务内容、回复或执行任何群功能。

不是绑定者的人即使直接私聊微信 ClawBot，我也会安静地忽略。系统只记录不含正文的安全审计信息，不会为对方创建用户资料或对话记录。

## 九、从微信发起 QQ 专属操作

普通聊天和平台无关功能可以直接在微信使用。少数只属于 QQ 的操作不能在微信里直接越权执行。

碰到需要授权的操作时，我会这样处理：

1. 瑞希会保留这次请求来自微信。
2. 确认票据必须由绑定 QQ 用户在 QQ 私聊批准。
3. 如果操作涉及 QQ 群，需要先明确指定目标群。
4. 执行结果会回到原来的微信私聊，不会改发到无关会话。

这条规则用于防止拿到微信会话的人直接操作 QQ 权限。不要把 `/工具确认` 票据发给其他人。

## 十、安全与隐私说明

- `bot_token`、登录临时凭据、同步游标和微信上下文令牌会加密保存在独立 SQLite 中。
- 微信上下文令牌不会交给模型、写入记忆或出现在普通日志里。
- 群访问和非绑定者访问只记录必要的匿名审计信息，不记录消息正文。
- 入站媒体只有通过绑定者私聊门禁后才会下载。
- 出站文件只能来自瑞希工具生成目录或微信媒体缓存目录，不能把任意本地文件发到微信。
- 二维码只在 QQ 私聊生成，并且大约 5 分钟后过期。
- 瑞希不会通过绑定流程索要微信密码、短信验证码或其他账号密钥。

## 十一、常见问题

| 情况 | 处理方法 |
| --- | --- |
| `/微信 绑定` 没有反应 | 确认是在机器人 QQ 私聊中发送，并联系管理员确认微信功能已经启用。 |
| QQ 群里没有二维码 | 这是安全限制；转到 QQ 私聊重新发送 `/微信 绑定`。 |
| 二维码过期 | 在 QQ 私聊重新发送 `/微信 绑定`，使用新二维码。 |
| 提示已经绑定 | 使用 `/微信 状态` 查看；确实需要更换时发送 `/微信 换绑`。 |
| 换绑要求工具确认 | 在同一个绑定 QQ 私聊发送 `/工具确认 <票据编号>`。 |
| 新二维码没扫成功 | 旧绑定会继续保留，重新发起换绑即可。 |
| 微信私聊完全不回复 | 确认当前微信就是绑定者；非绑定者会被静默拒绝。仍无回复时，让管理员检查 worker 状态。 |
| 微信群里不回复 | 这是强制设计，微信群功能不能开启。 |
| 语音提示没有可识别文字 | 微信没有随消息提供转写；改用文字发送。 |
| 文件发送失败 | 检查是否超过 20 MiB；过大文件需要缩小后重试。 |
| 主动提醒还在 QQ | 在 QQ 私聊发送 `/微信 通知 微信`，再用 `/微信 状态` 确认。 |
| 两个平台会不会重复提醒 | 不会。主动通知平台只能选择 QQ 或微信。 |
| 解绑会不会清空记忆 | 不会。解绑只移除微信通道，QQ 身份及其用户数据保留。 |
| 被拉进微信群怎么办 | 无需在群里操作；瑞希不会处理群消息，可由账号管理者自行退出群。 |

## 十二、命令速查

以下命令全部在 QQ 私聊使用：

| 命令 | 作用 |
| --- | --- |
| `/微信 绑定` | 首次申请约 5 分钟有效的绑定二维码。 |
| `/微信 状态` | 查看绑定状态和主动通知平台。 |
| `/微信 换绑` | 申请更换微信绑定，需要 QQ 私聊二次确认。 |
| `/微信 解绑` | 申请解除微信绑定，需要 QQ 私聊二次确认。 |
| `/微信 通知 QQ` | 将后续主动通知切换到 QQ。 |
| `/微信 通知 微信` | 将后续主动通知切换到微信。 |
| `/工具确认 <票据编号>` | 在绑定 QQ 私聊批准换绑、解绑或 QQ 专属操作。 |

最后提醒一次：绑定二维码和确认票据都只留在自己的 QQ 私聊里。把入口换到微信没有关系，但别把自己的门票顺手递给别人啦。
