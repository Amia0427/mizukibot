# QQ 绘图功能使用指南

更新时间：2026-07-30 21:17 +08:00

机器人可以把你描述的图表、流程图、海报或信息卡制作成 PNG 图片，并直接发送到当前 QQ 群聊或私聊。你只需用自然语言说明想画什么，不需要编写 HTML、SVG 或填写技术参数。

## 快速开始

- 私聊：直接发送绘图要求。
- 群聊：请先 `@机器人`，再发送绘图要求，避免消息被当作普通群聊内容忽略。
- 明确使用 SVG：说“用 SVG 绘制……”。适合流程图、关系图、架构图和简单矢量插画。
- 明确使用 HTML：说“用 HTML 制作……”。适合海报、信息卡、状态卡和排版较复杂的内容。
- 不指定技术方式也可以：直接说“制作一张……”，机器人会自行选择。

例如：

```text
@机器人 请制作一张本周学习计划信息卡，分为周一到周日，蓝绿色、简洁、竖版。
```

机器人完成后会在当前会话发送一张 PNG 图片。

## 可以制作什么

- 流程图、时间线、架构图、关系图、状态图
- 柱状图、折线图、饼图等数据图表
- 活动海报、公告图、倒计时图
- 课程表、计划表、对比表等表格图片
- 个人资料卡、任务状态卡、纪念日卡片
- 由文字、色块、线条和基础图形组成的简单插画

这项功能更适合结构清晰、文字可读的视觉内容，不适合写实照片、复杂人物绘画、网页截图或动态页面。

## 怎样描述得更准确

一条完整的要求最好包含以下信息：

```text
图片类型 + 标题/主题 + 必须出现的内容 + 布局 + 风格和配色 + 横版或竖版
```

没有说明的部分会由机器人自行决定。图表和表格应提供准确数据；绘图过程中不会自动从外部网页补齐资料。

### 流程图

```text
用 SVG 绘制一个“用户反馈处理流程图”：收到反馈 -> 分类 -> 指派负责人 -> 处理 -> 用户确认 -> 归档。横向布局，节点使用不同颜色，文字清楚。
```

### 信息卡

```text
用 HTML 制作一张“今日状态卡”：完成 4 项任务、专注 3 小时、剩余 2 项。深色背景，重点数字醒目，竖版。
```

### 数据图表

```text
制作一张月度阅读量柱状图：1 月 3 本、2 月 5 本、3 月 4 本、4 月 8 本。标出每根柱子的数值，白底，蓝绿配色。
```

### 海报

```text
用 HTML 制作一张读书会海报：标题“周末读书会”，时间“周六 19:30”，地点“线上语音房”，副标题“本期共读《小王子》”。温暖但简洁，竖版。
```

### 时间线

```text
用 SVG 绘制项目时间线：8 月 1 日需求确认、8 月 5 日原型评审、8 月 12 日开发完成、8 月 15 日上线。横向排列，突出上线节点。
```

## 修改刚生成的图片

继续回复修改要求即可，最好引用机器人刚发送的图片，并明确哪些内容保持不变。

```text
保持内容不变，把背景改成白色，标题加大，时间节点改为纵向排列。
```

如果机器人没有正确关联上一张图，请在新消息中重新写出原始内容和修改要求。内容较多或文字过密时，建议减少单图内容，或分次制作多张图片。

## 内容与资源限制

- 用户请求和图片中的可见文字都会在发送前接受敏感词审查；未通过时不会生成或发送图片，管理员也不能绕过。
- 请勿要求制作违法违规、色情、暴恐、涉枪涉爆或其他不当内容，也不要使用拆字、谐音或变形文字规避审查。
- 图片不能加载网络图片、外部字体、网页链接或本地文件，也不能包含脚本、表单、网页框架、音频或视频。
- 请用自然语言描述想要的效果，不要提交现成的 HTML/SVG 代码让机器人直接执行。
- 单张图片适合有限内容；超长流程、密集表格和大量小字可能影响可读性。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 群聊中没有响应 | `@机器人` 后重新发送完整要求。 |
| 提示“图片内容未通过敏感词审查” | 检查并移除违规或容易产生歧义的内容；如确认是误拦，请联系管理员。 |
| 提示“图片渲染失败” | 简化布局或减少内容后重试；复杂排版可明确改用 HTML，流程图可明确改用 SVG。 |
| 提示“图片已渲染，但发送失败” | 稍后重新发起请求；这是 QQ 发送环节失败。 |
| 提示“QQ 图片渲染能力尚未启用” | 联系机器人管理员检查服务状态。 |
| 图片文字太小或内容拥挤 | 减少单图内容、改为竖版，或将内容拆成多次请求。 |
