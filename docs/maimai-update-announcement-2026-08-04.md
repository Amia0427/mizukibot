# 舞萌谱面查询与成绩分析更新公告

更新时间：2026-08-04 12:19 +08:00

以下文案面向已经启用舞萌功能的机器人实例，可直接用于 QQ 群公告、频道公告或版本更新日志。

## 群公告短版

```text
【舞萌功能更新】

现在可以直接问机器人舞萌曲目、定数、标准/DX、紫谱/白谱、物量和手法了，也可以分析单张谱面的纵连、交互、滑键、双押、变速和代表高强度段。

试试这样问：
1. @机器人 舞萌找 5 张定数 13.7 到 14.0 的 DX 紫谱。
2. @机器人 比较舞萌 PANDORA PARADOXXX 紫谱和白谱的定数、物量。
3. @机器人 分析舞萌 PANDORA PARADOXXX 白谱，告诉我主要难点。

普通谱面查询无需绑定。需要个人成绩分析时，请私聊发送 /mai bind <Import-Token>，绑定后可以问“根据我的成绩分析舞萌手法弱项”。Token 不要发在群里，个人成绩问题也建议私聊。

说明：弱项只是基于成绩相关性的推断，代表高强度段不等于你的实际掉音位置；新谱可能有一天左右的同步延迟。
```

## 更新日志长版

```text
【更新公告｜舞萌谱面查询与个性化成绩分析】

舞萌查询功能现已加入机器人。

本次更新支持：
• 按曲名、定数范围、标准/DX、绿黄红紫白难度查找谱面
• 比较同一曲目的不同谱面、定数和物量
• 分析单张谱面的结构特征与最多 3 个代表高强度段
• 绑定个人成绩后，推断可能的手法弱项

普通查询不需要命令，直接自然语言提问即可：
“舞萌找 5 张定数 13.7 到 14.0 的 DX 紫谱。”
“舞萌这首歌紫谱和白谱哪个更难，物量差多少？”
“分析舞萌 PANDORA PARADOXXX 标准白谱，重点看纵连和变速。”

个人成绩功能请在私聊使用：
/mai bind <Import-Token>  绑定并验证成绩
/mai status               查看绑定和数据版本
/mai refresh              刷新成绩
/mai unbind               清理本地凭据和成绩数据

绑定后可以问：
“根据我的成绩分析舞萌手法弱项。”
“根据我的成绩分析舞萌弱项，重点看纵连。”

隐私提醒：Import-Token 只能私聊发送，不要贴到群聊、截图或转发。个人分析虽然可以在群聊触发，但结果会公开显示，建议在私聊使用。

功能边界：弱项结论来自成绩与谱面特征的相关性，不是单局复盘；机器人无法定位你的实际掉音位置，也不会修改游戏数据。谱面数据按计划同步，新谱或低置信谱面可能暂时没有完整分析。

使用建议：需要按手法挑练习谱时，先按定数、标准/DX 和难度找候选，再指定其中一张分析纵连、交互、滑键等手法。
```
