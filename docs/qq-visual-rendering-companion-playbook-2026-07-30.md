# 瑞希的 QQ 绘图陪伴玩法手册

更新时间：2026-07-30 21:30 +08:00

有些心情只说一句好像太轻，写成长篇又有点累。那就交给我吧：我可以把你的一天、某段回忆，或者大家一起闹出来的点子，做成一张能留在 QQ 里的图片。

这本手册前半部分都是现在就能玩的内容，示例可以直接复制。最后的“以后可能一起玩的功能”全部尚未上线，我会明确标出来，不拿愿望假装成已经有的能力。

基础操作、支持格式和失败处理见[QQ 绘图功能使用指南](qq-visual-rendering-user-guide-2026-07-30.md)。

## 先这样叫我画图

私聊里直接把要求发给我就好；群聊里请先 `@机器人`，不然我可能会把消息当成大家正在聊天。

你不需要写 HTML 或 SVG 代码。告诉我内容、布局、颜色和横竖版就够了；没说的部分，我会自己搭配。

```text
请制作一张信息卡：主题是“今天也有好好生活”，必须包含完成的三件小事，粉色和青绿色，竖版，文字清楚。
```

## 私聊陪伴：现在就能玩

### 今日心情天气卡

**什么时候玩：** 心情说不清楚，或者想给今天留一张小小的天气记录时，就来找我。

**你告诉我：** 今天像什么天气、心情强度、发生的一件事，以及想要的颜色。没有真实天气数据也没关系，我们画的是心里的天气。

**直接这样说：**

```text
请制作一张“今日心情天气”信息卡：天气是多云转小雨，心情 3/5，发生的事是计划被临时打乱；用灰蓝色和一点浅粉，竖版，不要补充我没说过的经历。
```

### 陪伴能量状态卡

**什么时候玩：** 想看看自己今天还剩多少力气，或者只是想让我陪你把状态整理一下时。

**你告诉我：** 精力、社交电量、专注度和最想完成的一件小事。数值由你决定，我不会替你做心理判断。

**直接这样说：**

```text
请制作一张“今日陪伴能量”状态卡：精力 40%、社交电量 20%、专注度 60%，今天只想完成“洗完澡早点睡”；低饱和紫色和青绿色，竖版。
```

### 晚安小结与今日三件小事

**什么时候玩：** 睡前不想写日记，但又不想让这一天什么都没留下时。

**你告诉我：** 今天完成的三件事、一句想带到明天的话，以及想要安静还是可爱的风格。

**直接这样说：**

```text
请制作一张晚安信息卡：今天完成了按时吃饭、回复重要消息、散步二十分钟；留给明天的话是“慢一点也算向前”；深蓝背景、暖黄色点缀、竖版。
```

### 纪念日票根与回忆明信片

**什么时候玩：** 想纪念认识的日子、一次见面、一场演出，或者任何只有你知道为什么重要的瞬间时。

**你告诉我：** 日期、地点、事件、想保留的一句话。图片只使用你这次提供的内容，不会自动把私聊回忆拿去别的会话。

**直接这样说：**

```text
请制作一张纪念日海报，做成电影票根风格：日期是 2026 年 7 月 30 日，地点是线上，事件是“第一次一起做心情卡”，保留文字“这一天值得存档”；粉黑配色，横版。
```

### 一周成长轨迹与习惯打卡

**什么时候玩：** 想看见自己一周里那些很小、却确实发生过的进步时。

**你告诉我：** 每天完成了什么、哪些天没有完成、最想突出的一次进步。空白和中断也可以如实保留。

**直接这样说：**

```text
请制作一张“一周成长轨迹”时间线：周一早睡、周二散步、周三未完成、周四读书 30 分钟、周五整理房间、周六和朋友聊天、周日休息；突出“周日允许自己休息”，横版，清爽绿色。
```

### 娱乐抽签卡

**什么时候玩：** 两个都无伤大雅的选项纠结太久，想要一点仪式感帮你结束选择时。

**你告诉我：** 已经选好的结果、候选项和想要的卡面主题。我可以把结果画得很有气氛，但它只用于娱乐，不替你决定医疗、金钱、安全或其他重要事情。

**直接这样说：**

```text
请制作一张娱乐抽签结果卡片：候选项是“看一集动画”和“下楼散步”，本次结果是“下楼散步”；做成轻松的夜间霓虹风，竖版，并写明“仅供娱乐”。
```

### 故事分支流程图

**什么时候玩：** 一起编故事、跑轻量剧情，或者想把脑子里乱成一团的剧情线摊开看看时。

**你告诉我：** 起点、选择、不同结局和已经确定的设定。每个节点尽量短一点，图会更清楚。

**直接这样说：**

```text
请绘制一张故事分支流程图：起点是“深夜收到一封没有署名的信”；选择一“立刻拆开”通向旧照片，选择二“等到天亮”通向陌生来电；两条线最后汇合到“去车站找答案”，暗色悬疑风，横版。
```

### 角色关系图

**什么时候玩：** 原创角色越来越多，谁认识谁、谁瞒着谁已经快记不住时。

**你告诉我：** 角色名字、两两关系和要强调的阵营。关系不确定就写“不确定”，我不会替你补成事实。

**直接这样说：**

```text
请绘制一张角色关系图：林雾和夏川是搭档，夏川暗中调查顾言，顾言欠林雾一次人情；三个人都与“旧车站事件”有关。用不同线型区分合作、调查和人情，深色背景，文字清楚。
```

## 群聊娱乐：现在就能玩

群里的图可能会被很多人看到。涉及昵称、语录、经历或统计时，先确认当事人同意，再 `@机器人` 把已经确认的内容交给我。

### 群活动海报与邀请函

**什么时候玩：** 临时开黑、观影、读书会、生日祝福或语音夜聊，需要一张比纯文字更有气氛的通知时。

**你告诉我：** 活动名称、时间、地点、参与方式和必须出现的提醒。

**直接这样说：**

```text
@机器人 请制作一张群活动海报：标题“周五夜间观影”，时间“周五 21:00”，地点“群语音”，影片由到场成员投票决定，提醒“提前十分钟集合”；紫色和亮黄色，竖版。
```

### 投票结果图表

**什么时候玩：** 投票已经结束，想把结果做成一眼就能看懂的图片时。

**你告诉我：** 每个选项的票数和总票数。我不会自动读取 QQ 投票，也不会编造缺失数据。

**直接这样说：**

```text
@机器人 请制作一张群投票结果图表：桌游夜 8 票、观影夜 5 票、自由聊天 3 票，共 16 票；使用横向条形图，标出每项票数，白底，蓝橙配色。
```

### 群挑战、宾果卡与任务板

**什么时候玩：** 想给周末加一点小游戏，或者把共同目标变成可以截图打勾的任务板时。

**你告诉我：** 格子数量、每格任务、完成规则和截止时间。现在的图片是静态 PNG，需要大家自己保存或标记进度。

**直接这样说：**

```text
@机器人 请制作一张“周末快乐宾果”卡片，3×3 格，内容是早起吃早餐、分享一首歌、散步十分钟、拍天空、整理桌面、夸一位群友、喝够水、看一集喜欢的作品、早点睡；明亮杂志风，方形布局。
```

### 群友语录卡

**什么时候玩：** 群里出现一句大家都想保存的话，而且说话的人同意被做成图片时。

**你告诉我：** 已获同意的原话、署名方式、日期和背景风格。没有同意就不要把别人的私密表达做成公开卡片。

**直接这样说：**

```text
@机器人 请制作一张群友语录信息卡：原话是“慢慢来，群还在，人也还在”，署名“经本人同意：小安”，日期“2026-07-30”；深蓝夜空风，只用文字和基础图形，竖版。
```

### 多人接力海报

**什么时候玩：** 大家想一人加一点内容，最后拼成一张共同作品时。

**你告诉我：** 本轮新增内容、必须保留的旧内容和允许修改的区域。最好引用上一张图，避免我接错版本。

**直接这样说：**

```text
@机器人 请制作一张接力海报：保留标题“我们的夏夜”和上一版的星空、车站元素；本轮新增一台自动售货机和文字“下一站见”；其他内容不要改，横版。
```

## 想改上一张图时

引用我刚发的图片，再告诉我“什么不动、改什么、新增什么”。这样最不容易把已经喜欢的部分一起改掉。

```text
请重新制作上一张信息卡：保持全部文字和配色不变，只把横版改成竖版；标题移到顶部，新增一条细边框，其他内容不要改。
```

如果我没有正确接住上一版，就把原始内容和修改要求一起重发。内容太多时，拆成两张会比把所有小字硬塞进一张更好看。

## 我会守住这些边界

- 我只根据你明确提供的内容画图。没有数据、日期或人物关系时，我不会把猜测画成事实。
- 私聊里的回忆不会因为一句模糊要求就被带进群聊；想公开某段内容，请在群里重新给出并确认可以分享。
- 心情卡和能量卡只是整理感受，不是心理评估、诊断或医疗建议。感觉持续难受时，请优先联系可信赖的人或专业支持。
- 抽签卡只增加一点娱乐仪式感，不替你做医疗、法律、金钱、安全或人生重大决定。
- 用户要求和图片里的可见文字都会接受敏感词审查；违法违规、色情、暴恐、涉枪涉爆等内容不会生成或发送，也不能通过拆字、谐音或变形规避。
- 我现在发送的是静态 PNG，不能点击、自动计分或保存游戏进度，也不能加载网络图片、外部字体、网页或本地文件。

## 以后可能一起玩的功能

下面六项全部是未来构想，**尚未上线**。现在直接发这些要求，只能得到一张普通静态图片，不会自动定时、读记忆、累计收藏或保存游戏状态。

### 尚未上线：定时早安、晚安与纪念日卡片

以后也许可以由你主动开启固定时间和频率，我再按时送上一张不重复的问候卡；还需要补齐取消入口、频率限制和打扰保护。

### 尚未上线：授权回忆周报与纪念册

以后也许可以让你先选择时间范围和允许使用的记忆，再生成一周回顾或纪念册；私聊内容默认不能进入群聊版本，生成前还需要预览和确认。

### 尚未上线：陪伴成就与收藏册

以后也许可以把“连续记录心情”“完成一周小目标”变成长期保存的徽章和收藏页；这需要可靠的进度存储、撤销和数据导出能力。

### 尚未上线：有状态的抽卡与收藏玩法

以后也许可以拥有卡池、抽取记录、保底和收藏册，而不是每次只画一张互不关联的结果图；概率必须公开，且不能与付费或现实收益挂钩。

### 尚未上线：可保存进度的分支故事与群接龙

以后也许可以记住每轮选择、当前章节和参与者，让故事隔天继续；还需要处理版本冲突、参与权限和随时结束剧情的入口。

### 尚未上线：群活动统计与赛季榜

以后也许可以在群成员明确同意后统计指定活动，自动生成赛季榜和结算海报；不会默认分析所有聊天，也不能把活跃度包装成对人的价值排名。
